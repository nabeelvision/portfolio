# Nabeel Vision — Portfolio (React + TypeScript)

A modern, responsive portfolio application for **Nabeel Ahmad** (Full Stack AI & Web Developer), rewritten from static HTML to a modular **React + TypeScript + Vite** architecture while faithfully preserving the original Arctic Frost design aesthetic and interactive features.

## ✨ Features

- **Arctic Frost Design System**: Faithful reproduction of the cyan/blue gradient theme, dot grid background, rotating glowing photo rings, and glassmorphism navbar.
- **Hero & Profile Showcase**: High-impact introduction with dynamic status badges ("Available for Work", "5+ Years Exp.", "50+ Projects") and profile visual.
- **Key Metrics & Statistics**: Projects completed, client satisfaction rate, and years of experience.
- **Skills & Expertise Grid**: Categorized cards for Frontend Development, Backend Architecture, AI Integration & Automation, and Machine/Deep Learning.
- **Featured Projects & Case Studies**:
  - **SquooshLite** (Free image compressor with direct live link to Netlify)
  - **ShopNova** (E-commerce platform)
  - **DataPulse** (Analytics dashboard)
  - Interactive case study modal with technical highlights and tech stack tags.
- **Career Timeline**: Detailed chronology of roles at TechCorp Solutions, Digital Craft Agency, and StartupHub Pakistan.
- **Interactive Contact Hub**:
  - Direct communication channels (Email with copy button, LinkedIn, GitHub, Facebook)
  - Quick project inquiry form with validation and instant feedback.
- **Responsive & Accessible**: Fully optimized for mobile, tablet, and desktop viewports with animated scroll reveal.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: CSS Custom Properties (Arctic Frost theme), Modern Flexbox & Grid
- **Icons**: Lucide React + custom inline brand SVGs
- **Typography**: Bricolage Grotesque & Lora (Google Fonts)

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
